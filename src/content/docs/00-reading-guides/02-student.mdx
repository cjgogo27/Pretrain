## 先看到全貌，再跑出一条链

建议顺序读第 1 章，知道模型在学什么、系统如何连接；再读第 2 章和第 3 章，理解文本怎样成为 token、token 怎样变成预测。第 4 章把预测误差变成权重更新，第 5 章解释怎样判断它是否有用。

| 阶段 | 阅读范围 | 自己做一次 |
| --- | --- | --- |
| 建立地图 | 1.1–1.3 | 画出数据流和计算流 |
| 准备材料 | 2.1–2.5 | 手写一段输入和右移标签 |
| 理解网络 | 3.1–3.5 | 算一个 logits 张量大小 |
| 理解更新 | 4.1–4.6 | 计算全局批量与学习率位置 |
| 理解证据 | 5.1–5.5 | 分清 loss、PPL 和任务准确率 |
| 完成实验 | 6.1–6.5 | 训练、恢复并写一张模型卡 |

## 先自己回答，再打开答案

每节开始有三类问题。至少先记住“学生”问题，读完用自己的话解释，再打开折叠答案。能复述词语不等于理解：尝试写出一个具体形状、数值或失败例子。

数学基础不足时，可以先把 3.1 里的 $B,S,d,V$ 对照实验配置；理解平均交叉熵后再看反向传播。分布式章节先掌握“复制什么、分片什么、交换什么”，不必第一遍记住所有通信 API。

## 一条最短可运行路线

[1.3](/Pretrain/01-system-overview/03-pretraining-system-architecture/) → [2.4](/Pretrain/02-data-tokenization/04-packing-and-loading/) → [4.1](/Pretrain/04-training-distributed/01-loss-and-gradients/) → **[6.1 环境准备](/Pretrain/06-tools-practice/01-engineering-and-environment/)** → [6.2](/Pretrain/06-tools-practice/02-minimal-pretraining/)。先在虚拟环境安装 CPU 依赖，再生成语料和训练；不必为运行教学实验安装网站依赖。

第一次运行后，核对 437,888 参数、每更新 256 token 和 100 步的 25,600 token；对照正文曲线和生成片段，再运行恢复验证。理解单步后再做 [6.3 固定样本与多步恢复对照](/Pretrain/06-tools-practice/03-single-to-multi-gpu/)。最后读[训练阶段怎样连接](/Pretrain/00-reading-guides/04-training-stages/)，把数据、学习率和长度放回同一条 token 轴。

有余力时，运行 2.2 的十文档清洗，解释一次误删与漏删；再用 2.1 的三个配对种子比较领域与通用 loss。4.5 的 TP 代数和 PP 时间线可以离线核对，5.4 的 CPU 等待实验用于理解“证据→最小改动→复测”。不必第一遍全部运行。

记录实验时写“我检查了什么、看到了什么、它能支持什么结论”。示例文本质量差不代表你没学会系统；它的规模和语料本来只为机制演示设计。
