## 现场问题

你有一个通用基础模型，想让它熟悉新的技术领域。只用领域文档继续训练后，术语更熟悉了，通用写作和其他任务却变差。

> 怎样增加领域知识，同时知道自己付出了什么代价？

## 先分清恢复与新阶段

**持续预训练（Continued Pretraining，CPT）**从已有权重出发，通常沿用语言建模目标，在补充语料上继续学习。它与“从同一次运行的检查点恢复”不同：数据分布、学习率、训练预算甚至上下文方案都可能发生变化，应建立新的运行身份。

已有模型带来能力与偏好，也带来分词器和架构约束。未经设计直接换分词器，容易使嵌入含义错配；增大上下文还需要位置方案和长文本评估配套。

## 把迁移收益与遗忘同时测

| 设计项 | 要回答的问题 | 最小证据 |
| --- | --- | --- |
| 领域数据 | 是否覆盖目标任务与表达 | 分层清单与样本审阅 |
| 通用混合 | 是否保留旧分布 | 混合策略与重复程度 |
| 学习率与预算 | 改动是否过快、是否学足 | 短跑曲线与固定 token 对照 |
| 领域评测 | 新能力是否改善 | 未见领域验证与任务 |
| 通用回归 | 是否损害原有能力 | 与起始模型相同条件比较 |

**灾难性遗忘（Catastrophic Forgetting）**指适应新数据时旧能力明显退化。混入通用数据、控制训练量和调节更新方式可能缓解，但具体效果要实验确认，不能保证某个固定比例足够。

> **一句话听懂**：持续预训练是在已有能力上继续改变分布，验收既要看新增内容，也要看原有能力保留得怎样。

## 权重加载与优化器策略

新阶段可以选择重建优化器，也可以在有充分理由时迁移部分状态；两者不是同一种实验。记录起始检查点、保留哪些状态、学习率是否重新预热、消费了多少新 token。

不要删去严格恢复检查来启动新阶段。本轮加入教学级 `--init-weights`：只取权重，核对架构与编码，再建立新 AdamW、新学习率计划、从零开始的计数和新随机流；不会沿用来源优化器与采样器。它仍不是生产 CPT 平台。

## 教学级新运行：只继承权重

先完成 6.2 的 100 步实验，再用新输出目录：

```bash
python examples/train.py --data runs/data --out runs/stage2 --steps 20 --lr 0.0001 --warmup 5 --init-weights runs/tiny/latest.pt
```

`--init-weights` 与 `--resume` 互斥。这个入口允许数据与优化计划变化，架构、编码及 `seq-len` / 位置表须匹配，不做长上下文迁移。随机生成器重新从新运行的 seed 开始；若仍用相同 seed 和语料，可能重复早期窗口，“重置”不等于保证新样本。

**本轮实际运行了同样的 100→20 步、同一份语料的新运行**：启动日志 `start_step=0, start_tokens=0, initialization.kind=weights_only, source_step=100`；最终 `step=20, tokens=5120`，新检查点保存来源文件哈希。自动测试另外检查新 AdamW 的内部 step 从零建立，且在改变数据后可通过权重初始化开始新运行。

成功条件是日志与新检查点说明重置策略，而不是 loss 达到某个预定门槛。常见失败包括来源架构 / 编码不匹配、同时指定两种初始化方式、输出目录已有旧日志；按错误核对输入，不把旧优化器改名冒充新阶段。

上述运行只验证**状态切换机制**，同一语料上的额外训练不等于领域迁移证据。要做真实 CPT，应换成经过 2.5 验收的领域数据，建立新的数据清单，再同时评测领域收益和通用退化；这部分配比 / 领域对照本轮未执行。跨阶段计划可对照[训练阶段怎样连接](/Pretrain/00-reading-guides/04-training-stages/)。

## 先做受控的候选比较

以起始模型为基线，固定领域训练 token，比较纯领域与领域加通用混合等少量候选。用同一套领域与通用评测选定后，再保留独立测试确认。若目标是指令遵循，单纯 CPT 未必满足，需要后训练目标与数据配套。
