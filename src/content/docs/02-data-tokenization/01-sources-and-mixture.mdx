## 现场问题

你有网页、技术文档和代码三类数据。网页最多，于是按文件大小直接混在一起；训练后，技术术语的表现却没有明显改善。

> 文件最多的来源，应该占最多训练份额吗？

## 数据集不是一个文件夹

**数据混合（Data Mixture）**描述训练时从不同来源、语言和领域抽样的分布。原始字节数、文档数与 token 数不是同一单位。中文、英文、代码经过同一分词器后，每字节对应的 token 数可能不同；配比需要明确以什么为分母。

先写数据清单，再讨论比例。来源清单至少包含获取方式、可使用范围、语言、领域、时间范围、清洗版本、保留文档数和 token 数。一个来源很大，也可能主要是模板、导航和重复转载。

| 来源 | 可能带来什么 | 常见质量问题 | 需要记录什么 |
| --- | --- | --- | --- |
| 网页正文 | 广泛话题与自然表达 | 模板、广告、转载、乱码 | 抓取批次、域名、正文抽取版本 |
| 技术与学术文本 | 结构化解释与专业术语 | 公式丢失、断行、版本重复 | 来源、文档版本、解析策略 |
| 代码 | 语法与程序结构 | 生成文件、重复仓库、敏感字符串 | 仓库版本、语言、许可与过滤规则 |
| 自有领域材料 | 目标任务术语与业务知识 | 格式不统一、隐私字段、覆盖狭窄 | 授权范围、脱敏版本与时间 |

## 配比决定模型反复看见什么

假设清洗后有 80M 网页 token 和 20M 技术 token。按现有量单遍读取，技术材料占 20%。如果训练采样选择 50% 技术材料，技术池的消耗速度提高，会更早发生重复。采样权重与唯一数据量应同时报告。

设来源 $i$ 的采样概率为 $p_i$，总训练量为 $D$，那么期望来自该来源的训练 token 为 $p_iD$。若可用唯一 token 数为 $U_i$，$p_iD/U_i$ 可以粗看重复程度，但打包、过滤和采样实现会影响精确结果。

> **一句话听懂**：数据配比决定模型把有限学习机会花在哪里；比例之外，还要看每类数据有没有足够的新内容。

## 用小规模实验选择配比

先确定需要保留哪些能力，再固定分词器、模型、总训练 token 和评测设置，对照两种配比。看总体指标，也看各领域的损失与任务表现。只增加某领域数据同时增加训练总量，无法单独证明收益来自配比。

教学语料全部由项目原创，故意缩小了数据来源的不确定性。生产项目应对每类来源独立抽样审阅，核对文字能否读通、结构是否保留、时间范围是否满足需求。抽样得到的质量结论只覆盖对应分层，不能直接推及所有语料。
