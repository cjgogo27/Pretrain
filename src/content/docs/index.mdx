## 这本书解决什么问题

预训练项目里，数据、模型、平台和评测常说着不同的语言。这本教程从“文本怎样变成一次权重更新”出发，把它们放进同一张系统图，再逐层拆开。

六章、29 个教学小节，从数据清洗与分词，到 Transformer、预算、分布式、训练诊断和交付。先看系统，顺着接口读，最后亲手跑一次小模型。

1.3 沿 `Hi!` 的真实字节 ID 贯通一次更新；[训练阶段怎样连接](/Pretrain/00-reading-guides/04-training-stages/)再把学习率、配比、长度与检查点放在累计 token 轴上。第 6 章展示绑定环境与输入身份的实际曲线、生成片段和验证结果。

## 贯穿案例：TinyPretrain

使用 257 项字节词表、2 层因果 Transformer、隐藏维度 128、上下文 64。语料由项目原创生成，无需下载模型或数据。你会得到日志、检查点、生成片段，并验证中断恢复。

<Aside type="note" title="简化、算例与实测">
  小模型用于验证机制，不代表通用大模型能力。1B 参数与 20B token 的预算是单独的假设算例。文中明确区分估算、设计选择和实际运行检查；实际验证记录见仓库 VALIDATION.md。
</Aside>
